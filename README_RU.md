# Камера наблюдения для Android

[English version](README.md) · [Релизы](https://github.com/rocketsvm/android-surveillance/releases)

Превращает Android-телефон в IP-камеру наблюдения:

- **Живое видео H.264** в браузере на компьютере или другом телефоне — с задержкой около полсекунды,
  без плагинов и без интернета (всё работает в локальной сети).
- **Работает с выключенным экраном** и после выхода из приложения; переживает перезагрузку телефона.
- **Детектор движения** с настраиваемой чувствительностью и зонами исключения.
- **Запись по движению** (с несколькими секундами *до* события), **непрерывная** или **ручная**;
  автоочистка старых записей по месту, объёму или сроку.
- **Просмотр и скачивание записей** из браузера, журнал событий.
- **Все настройки** — и на телефоне, и в браузере (одни и те же, меняются синхронно).
- Дата/время и название камеры поверх видео, фонарик, зум, выбор камеры (включая широкоугольную),
  звук с микрофона (по желанию), пароль на доступ.
- Поток для **видеорегистраторов, VLC, Home Assistant**: `rtsp://<адрес>:8554/live`
  (H.264 + AAC, RTP по TCP или UDP) и `http://<адрес>:8080/live.mp4`.
- **Уведомления в Telegram** через своего бота: снимок при движении, видео записи,
  отключение зарядки (например, пропал свет), сбой камеры.

## Установка

1. Скопируйте `SurveillanceCamera.apk` на телефон и откройте его (при запросе разрешите установку
   из этого источника).
2. Запустите «Камера наблюдения» — откроется пошаговая настройка:
   - разрешения на камеру и уведомления;
   - «Без ограничений» для батареи (иначе система может усыпить камеру);
   - адрес для подключения и QR-код;
   - автозапуск после перезагрузки (по желанию).

Требуется Android 8.0 или новее. Лучше всего — отдельный телефон на постоянной зарядке.

### Советы по прошивкам

- **Samsung**: «Настройки → Приложения → Камера наблюдения → Батарея → Без ограничений».
  В «Обслуживание устройства → Автооптимизация» отключите перезагрузку по расписанию
  (или включите автозапуск камеры).
- **Xiaomi / Redmi / POCO**: в настройках приложения включите «Автозапуск» и
  «Контроль активности → Нет ограничений».
- **Huawei / Honor**: «Запуск приложений» → ручное управление, разрешить работу в фоне.
- Блокировку экрана на телефоне-камере лучше отключить: после перезагрузки Android запускает
  приложения только после первой разблокировки.

## Как смотреть

Телефон и компьютер (или второй телефон) должны быть в **одной Wi-Fi сети**.
Адрес вида `http://192.168.1.23:8080` показан на главном экране приложения (там же QR-код) —
откройте его в браузере (Chrome, Edge, Firefox, Safari; на iPhone — iOS 17.1 и новее, на более
старых iPhone смотрите поток в приложении VLC по адресу RTSP).

- **Камера** — живое видео, снимок, ручная запись, фонарик, режим записи.
- **Записи** — по дням, с миниатюрами; просмотр, скачивание, удаление.
- **События** — движение, начало и конец записей, ошибки.
- **Настройки** — все параметры камеры, детектора, записи и доступа.

Чтобы адрес не менялся, закрепите IP за телефоном в настройках роутера (резервирование DHCP).

### Доступ из интернета

Самый простой и безопасный способ — VPN-сеть вроде **Tailscale** или **ZeroTier**: установите её
на телефон-камеру и на устройство, с которого смотрите. Адрес VPN появится в списке адресов
в приложении. Открывать порт на роутере можно только с установленным паролем.

### Пароль

«Настройки → Доступ → Пароль». Браузер покажет форму входа; VLC и регистраторы могут
использовать адреса вида `rtsp://admin:пароль@192.168.1.23:8554/live` или
`http://admin:пароль@192.168.1.23:8080/live.mp4`.

### Видеорегистратор, Home Assistant, VLC

- **VLC**: «Медиа → Открыть URL» → `rtsp://192.168.1.23:8554/live`.
- **Home Assistant**: интеграция Generic Camera, Stream Source `rtsp://192.168.1.23:8554/live`,
  Still Image `http://192.168.1.23:8080/api/snapshot.jpg`.
- **Регистраторы (Synology, Blue Iris, Frigate и др.)**: «RTSP / generic camera» с тем же адресом.
  Если регистратор пишет звук копированием через ffmpeg, ему нужен ключ `-copyinkf`
  (особенность ffmpeg для AAC по RTP) или перекодирование звука.

### Уведомления в Telegram

1. В Telegram откройте @BotFather → `/newbot` → получите токен.
2. Напишите своему боту любое сообщение.
3. «Настройки → Уведомления в Telegram»: вставьте токен, нажмите «Найти» у поля «ID чата»,
   включите «Присылать уведомления» и нажмите «Отправить тестовое сообщение».

Телефону нужен доступ в интернет. Частоту уведомлений о движении ограничивает
«Не чаще одного раза в … мин».

## Где хранятся записи

`Android/data/com.surveil.camera/files/recordings/<дата>/` во внутренней памяти или на SD-карте
(выбирается в настройках). Файлы — обычные MP4 (H.264, AAC), открываются любым плеером.
Если питание пропало посреди записи, ролик восстанавливается при следующем запуске.

## Для разработчиков

Сборка (JDK 17+, Android SDK с platform 37):

```bash
tools/gw.sh :app:assembleDebug        # APK: ~/.build/SurveillanceCamera/app/outputs/apk/debug/
tools/gw.sh :core:test                # модульные тесты ядра (JVM)
tools/gw.sh :core:runDev -PdevArgs="<папка> 8090"   # веб-интерфейс на ПК с фейковой камерой
```

Архитектура и правила — в [AGENTS.md](AGENTS.md), заметки и результаты проверок — в [NOTES.md](NOTES.md).

### HTTP API (кратко)

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/api/status` | состояние камеры, потока, детектора, записи, телефона, адреса |
| GET/POST | `/api/settings` | схема и значения настроек / изменение (`{"ключ": значение}`) |
| GET | `/api/recordings` | список записей и сведения о хранилище |
| GET | `/rec/<id>.mp4` | запись (поддерживает Range; `?download=1` — скачать) |
| POST | `/api/recordings/delete` | `{"ids": [...]}` |
| GET | `/api/snapshot.jpg?w=1280` | текущий кадр |
| POST | `/api/record` | `{"on": true}` — ручная запись |
| GET | `/api/events` | журнал событий |
| WS | `/ws/live` | живой поток fMP4 для MSE |
| WS | `/ws/events` | статус и события в реальном времени |
| GET | `/live.mp4` | живой поток fMP4 для VLC/ffplay/регистраторов |
| POST | `/api/notify/test` | тестовое сообщение в Telegram |
| POST | `/api/notify/chats` | чаты, писавшие боту (для поля «ID чата») |
| RTSP | `rtsp://<адрес>:8554/live` | H.264 + AAC для регистраторов и плееров |
